# Random forest

## Overall goal

Now that you have attempted the [pipeline homework](/exercises/pipeline/), this next one is meant to provide some deeper exposure to the classification workflow.

## Getting started

GitHub Classroom is no longer used. Start by opening the [random forest starter repository](https://github.com/ubern-mialab/ubern-mialab-2025-random-forest-03-classifier), selecting **Fork**, and creating the fork under your own GitHub account.

Clone your fork and start working on it. Work in your own fork, not in the `ubern-mialab` starter repository. If GitHub displays a 404 page, contact a teaching assistant to request access before forking.

The process is a little easier than earlier: there are no auto-graded tests, so you are more flexible this time. Commit and push your final work to your fork, then share the fork link and the URL or SHA of your final commit together with your best accuracies and hyper-parameters in the #random channel on Slack.
